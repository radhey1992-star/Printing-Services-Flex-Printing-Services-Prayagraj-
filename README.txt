# Flex Printing Services Prayagraj — Free Website

A responsive static website created from the supplied business screenshot.

## Files
- index.html — website
- style.css — design
- script.js — WhatsApp enquiry form

## Before publishing
1. Open `script.js`.
2. Replace `REPLACE_WITH_NUMBER` with the shop's WhatsApp number in international format, e.g. `919876543210`.
3. You can replace/add real shop photos later.

## Free hosting
Upload these files to a static host such as GitHub Pages, Netlify, or Cloudflare Pages. No paid hosting is required for the static site.
